# Kick TV для Hisense (VIDAA)

Неофициальное приложение Kick для телевизоров на **VIDAA**: эфиры, категории, каналы, записи, клипы, чат Kick со смайлами (Kick и 7TV), избранное, поиск, лента «Эфир». Управление с пульта. Оформление в стиле Kick: тёмный фон и фирменный зелёный. 27 языков интерфейса (язык берётся из настроек ТВ, его можно сменить в Настройках).

- **Разработчик:** [github.com/PainFrenemy2](https://github.com/PainFrenemy2)
- **Издатель:** Null/Code
- Сделано на основе [Twitch TV для Hisense](https://github.com/PainFrenemy2/TVAppTwitch-Hisense-): та же навигация с пульта, плеер и интерфейс.

## Какие телевизоры поддерживаются

Все телевизоры с системой **VIDAA** (VIDAA OS / VIDAA U): **Hisense** (A6, A7, E7, U7, U8, 58A6K и др.), а также **Toshiba**, **Sharp**, **Loewe**, **Daewoo** и другие марки с VIDAA.

Как понять, что у вас VIDAA: на главном экране ТВ есть **My Apps** / **Мои приложения**, а в **Настройки → Система → О телевизоре** указана VIDAA.

## 1. Включить GitHub Pages (один раз)

1. В репозитории откройте **Settings → Pages**.
2. **Source:** `Deploy from a branch`, **Branch:** `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты приложение заработает по адресу
   `https://painfrenemy2.github.io/TVAppKICK-Hisense--/`

## 2. Установить на телевизор

1. На ТВ откройте встроенный браузер и введите `hisense://debug`.
2. Заполните форму:

| Поле | Что вписать |
|---|---|
| **App Name** | `Kick` |
| **Thumbnail** | `https://painfrenemy2.github.io/TVAppKICK-Hisense--/icons/thumbnail.png` |
| **IconSmall** | `https://painfrenemy2.github.io/TVAppKICK-Hisense--/icons/icon-small.png` |
| **IconLarge** | `https://painfrenemy2.github.io/TVAppKICK-Hisense--/icons/icon-large.png` |
| **App Url** | `https://painfrenemy2.github.io/TVAppKICK-Hisense--/` |
| **Resolution** | `1080` |

3. Нажмите **INSTALL** — в **My Apps** появится чёрная плитка с зелёным логотипом Kick.

> Если `hisense://debug` не открывается, откройте адрес приложения во встроенном браузере ТВ и добавьте его в закладки.

Обновления приходят сами: приложение проверяет `version.txt` и перезагружается на новую версию (не во время эфира).

## Пульт

| Кнопка | Действие |
|---|---|
| Стрелки, OK | навигация, выбор |
| Назад | назад; на главной — меню, потом выход |
| CH+ / CH− | следующий / предыдущий эфир из того же ряда |
| ▶❚❚ / Стоп | пауза / закрыть плеер |
| ⏩ / ⏪ | перемотка записей |
| 🔴 красная | качество видео |
| 🟢 зелёная | чат |
| 🟡 жёлтая | добавить в избранное / убрать |
| 🔵 синяя | перезагрузить поток |

## Вход в Kick

Kick пока не даёт сторонним приложениям вход по коду (как Twitch на телевизорах), поэтому приложение работает **без входа**. Каналы, за которыми вы следите, добавляйте в **избранное** — они появятся в «Отслеживаемом» и первыми на главной. Ставки, баллы и отправка сообщений в чат без входа недоступны.

## Если что-то не грузится

Настройки → **Диагностика Kick**: показывает, отвечает ли каждый адрес Kick (эфиры, категории, канал, видео, клипы, поиск, чат). Скриншот этого экрана поможет быстро исправить проблему. Там же — «Сообщить о проблеме» (QR-код на Issues).
